पहली बार — तीन चीज़ें
─────────────────────

  1. GitHub CLI लगाओ और login करो

         sudo apt install gh
         gh auth login

     "GitHub.com" चुनना, फिर "HTTPS", फिर browser से login.

  2. git को अपनी पहचान बताओ (अगर पहले नहीं बताई)

         git config --global user.name "Kanak Prabhakar"
         git config --global user.email "तुम्हारा@email"

     Email वही डालना जो GitHub खाते में है, वरना commits तुम्हारे
     नाम से नहीं दिखेंगे.

  3. pariyojana.tsv में रास्ते ठीक करो

     मैंने जो रास्ते लिखे हैं वो अंदाज़े हैं. अपनी मशीन के असली
     रास्ते डालो. जो project अब मौजूद नहीं, उसकी लाइन हटा दो.

     ध्यान: खानों के बीच TAB होना ज़रूरी है, space नहीं.

राज़ जाँच के बारे में — यह छोड़ना मत
──────────────────────────────────────

  GitHub पर एक बार जो चला गया, वो हमेशा के लिए चला गया.

  Commit हटाने से भी नहीं जाता — GitHub पुराने commits अपने पास रख
  लेता है और वो URL से खुलते रहते हैं. Repo private कर दो, तब भी जो
  पहले copy हो चुका वो वापस नहीं आता.

  और bots GitHub को लगातार खंगालते हैं. Public repo में गई API key
  मिनटों में इस्तेमाल हो जाती है, घंटों में नहीं.

  इसीलिए script public project को तब तक push नहीं करता जब तक जाँच
  पास न हो. इसमें कोई ढील नहीं है, और नहीं होनी चाहिए.

  किसी एक project को अलग से जाँचना हो:

      python3 aujaar/raaz_jaancho.py ~/Desktop/कोई-project


public या private — कैसे तय करें
──────────────────────────────────

  public तब जब — कोई और उससे सीख सके, या तुम उसे दिखाना चाहते हो
                  (internship, admission, GitHub की शक्ल)

  private तब जब — किसी और का नाम/data उसमें है, या कुछ गुप्त हो
                  सकता है, या वो अभी अधूरा है

  शक हो तो private. Public बाद में एक क्लिक में हो जाता है.
  उल्टा नहीं होता — जो एक बार public हो गया, वो हो गया.
